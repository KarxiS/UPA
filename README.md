### Web Scraping Project - E-Shop Data Extraction

**Aktualizováno 17.9.:**  
Věnujte prosím pozornost parametrům vytvářené datové sady níže (minimální počet produktů a jejich parametrů). Vytvořená datová sada bude následně využita v projektu 3 pro analýzu. Proto jsme počty mírně navýšili.

#### Cíle projektu:
1. Získat automatizovaně seznam URL produktů z dynamických webových stránek.
2. Extrahovat klíčové informace (název, cenu a parametry) z více e-shopů.

#### Pokyny k řešení:
- Zvolte vhodný e-shop (ideálně zahraniční) s rozšířenými parametry produktů.
- Vyhněte se známým e-shopům (Amazon, Alza).
- Implementujte skripty pro automatizované získávání seznamu URL produktů (min. 150) a následnou extrakci parametrů.
  
#### Požadavky:
- Výstupy: soubory `urls.txt` (seznam URL) a `data.tsv` (TSV formát).
- Implementace: Běh na serveru merlin (např. Python, JS) bez využití online služeb.
- Dokumentace v `README` (název týmu, e-shop, význam sloupců v TSV).

Odevzdání jako ZIP obsahující všechny výstupy dle zadání.
